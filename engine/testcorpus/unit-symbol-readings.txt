# Lexime unit-symbol reading sets (plan unit-symbols-plan.md 8-1, PR2b).
#
# [S-std] and [ref] come first, then the reading sets (plan 8-1) made by a
# generator from the pinned Mozc dictionary (engine/data/mozc-raw/), the two
# accuracy corpora and snapshot-readings.txt only (F12). The file's sha256 is
# frozen before Phase 0 (plan 5 step 0). Nothing here is personal data.
# S-ctx is not in this file: its generator (rev4/prefix.py) is lost and the
# plan does not define its L and S (recorded in the PR notes).
#
# Grammar: UTF-8, one record per line, fields separated by a single TAB.
# Blank lines and lines starting with '#' are ignored. A line "[name]"
# starts a section; a record before the first section header is an error.
# A section name this reader does not know is an error (a new section needs
# its reader), so is an unknown record kind.
#
# [S-std]  the standard (reading, surface) pairs, one per line:
#     unit<TAB>reading<TAB>surface      a unit (名詞,接尾,助数詞), in rank order
#                                       within a reading (bit before b)
#     prefix<TAB>reading<TAB>surface    an SI prefix alone (記号,アルファベット)
#
# [ref]  where each unit reading's price comes from (T14, `dictool
#        check-units`). The Japanese name of a unit is its c_ref entry:
#     name<TAB>reading<TAB>ref surface<TAB>unit surfaces (comma, rank order)
#         c_ref = among the dictionary entries of (reading, ref surface), the
#         cheapest one whose left and right ids are both the unit's own id
#         (名詞,接尾,助数詞) if there is one, else the cheapest entry of the
#         surface (ids not considered); each unit's C = c_ref + its 1-based
#         rank. (Only なのめーとる 6059 / ぼると 4602 differ from the cheapest.)
#     alias<TAB>reading<TAB>surface<TAB>main reading
#         a variant reading: its C equals the main reading's unit of the same
#         surface (the same surface is not priced differently by reading).
#     family<TAB>id<TAB>base reading<TAB>compound readings (space-separated)
#         a unit-less base and the prefixed compounds the dictionary has for
#         it, all with a `name` line. A compound's difference is
#         (the cheapest entry's cost of its `name` surface) - (the same of the
#         base's): each word's cheapest entry, ids not considered, as for
#         `derived` below (not the same-id c_ref of a `name` line).
#     derived<TAB>reading<TAB>Japanese name<TAB>c_ref<TAB>unit surfaces<TAB>base reading<TAB>family ids
#         a reading the pinned Mozc has no Japanese name for. The name is a row
#         of extras' unit-names.tsv (名詞,一般, the only entry of that (reading,
#         surface)); its cost = c_ref written here = the value recomputed from
#         the dictionary: cheapest(base reading) + the median, floored (div by 2,
#         toward -inf), of the differences over all the listed families (more
#         than one family only for the bps readings, whose own system has no
#         compound). The recomputation takes each word's cheapest entry (not the
#         same-id entry, as `name` lines do). The check compares it with the
#         c_ref written here and with the unit's C, and fails if Mozc comes to
#         have the (reading, Japanese name).
#
# The reading sets (S-dig, S-kana, S-mid, S-pre, S-col, S-dig-col, S-mozc,
# S-ni): one record per distinct reading, in generation order:
#     r<TAB>reading<TAB>tag
#         tag = where the reading comes from; several origins are joined with
#         ','. S-dig: u (3 + unit reading) / multi; S-kana: the prefix
#         (さん / ひゃく / にひゃくごじゅう); S-mid: hand (20, written by hand);
#         S-pre: the S-std reading(s) it is a proper front part of (length >= 2);
#         S-col: i (a hiragana corpus / snapshot reading containing an S-std
#         reading) / ii:<S-std reading> (Mozc reading, up to 5 per reading,
#         cheapest first, cheapest entry in Japanese script) / iii:guard,
#         iii:word (by hand); S-dig-col: the unit reading u (3 + a Mozc
#         reading starting with u, up to 5, cheapest first); S-mozc: plain / 3 /
#         さん (the 186 readings of Mozc's 助数詞 entries with an ASCII letter);
#         S-ni: pre:<prefix> / num:<kana numeral> / hand.
# [S-snap] is a reference, not an expansion:
#     file<TAB>path<TAB>sha256 of that file when this set was generated
# `dictool check-units` parses every section (a malformed one fails) and
# prices only [S-std] / [ref].
#
# The derived readings and their inputs (counted on the built dictionary,
# engine/data/lexime.dict compiled from the pin in engine/data/mozc-pin.txt,
# after compile's role cost correction; derive again when the pin moves):
#   ぴこびょう  base びょう (秒), family びょう (ナノ秒 / マイクロ秒 / ミリ秒), median 4516
#   きろあんぺあ base あんぺあ (アンペア), family あんぺあ, median 2132
#   てらわっと  base わっと (ワット), family わっと, median 1167
#   てらふろっぷす base ふろっぷす (フロップス), family ふろっぷす (ペタフロップス), median 17
#   きろびっと  base びっと (ビット), family びっと (メガ..ペタビット), median 3446.5 floored 3446
#   ぺびばいと  base ばいと (バイト), family iec (キビ..テビバイト), median 4671.5 floored 4671
#   bps 系 4 読み base びーぴーえす (ビーピーエス), all 12 families together
#              (36 differences, the ワット時 one included), median 1936
